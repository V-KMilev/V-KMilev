### Buongiorno 👋

I build **[vkmEngine](https://github.com/V-KMilev/vkmEngine)**, a C++ game engine for Windows and Linux, and the libraries
under it, from the renderer to the physics. *Build games, not engines.*

[vkmengine.com](https://vkmengine.com) · [Docs](https://vkmengine.com/docs/) · [Projects](https://vkmengine.com/projects.html)

#### ▾ World

| | Entity | What it is |
|---|---|---|
| 🎮 | **[vkmEngine](https://github.com/V-KMilev/vkmEngine)** | The engine and its editor |
| 🖼️ | [vkmOpenGL](https://github.com/V-KMilev/vkmOpenGL) | OpenGL 4.5 objects and state for the renderer |
| 🌋 | [vkmVulkan](https://github.com/V-KMilev/vkmVulkan) | The Vulkan counterpart, planned |
| 🧱 | [vkmPhysics](https://github.com/V-KMilev/vkmPhysics) | Deterministic rigid bodies, bit-identical on any thread count |
| 🌐 | [vkmNetwork](https://github.com/V-KMilev/vkmNetwork) | UDP transport, reliable messages, a bit stream for game packets |
| 🔊 | [vkmAudio](https://github.com/V-KMilev/vkmAudio) | 3D sound that muffles and echoes by the world's shape |
| 🪟 | [vkmPlatform](https://github.com/V-KMilev/vkmPlatform) | Windows, input, threads and processes |
| 📜 | [vkmLog](https://github.com/V-KMilev/vkmLog) | Thread-safe logging |
